# 桌面集成验收

先运行 `./scripts/install.sh`，通过 `omarchy-shell shell summon jessie.switchboard
'{"mode":"workspace"}'` 或窗口模式测试面板。`status` 应报告 ready 和候选数量。
启用组合键使用 `./scripts/install.sh --bindings`；完成后可用 `--no-bindings` 恢复命令测试模式。

按计划书记录以下实机结果，不能用 offscreen 或假适配器替代：

- 当前 Omarchy、Hyprland、Quickshell、Qt 版本。
- 单屏当前工作区的窗口范围；双屏来源显示器的窗口范围及全显示器工作区网格。
- 选择期间真实窗口/工作区保持原状，Esc 取消后仍保持；确认后真实目标获得焦点。
- 正反向循环仅包含有窗口的工作区，按当前/上一个/MRU 排序；已有空工作区和未使用槽位均不显示。
- 从空工作区打开时，正向选择首项、反向选择末项；仅一个有窗口工作区时正反向都选中它。
- 所有工作区为空时显示空状态，确认后关闭；顶部工作区标题、底部新建入口和按键提示均不显示。
- 面板按卡片行数调整高度；卡片过多时滚动仍可显示选中项，方向键到末行后不会选中隐藏操作。
- 卡片全部可见时，从首行切到末行再返回，网格保持原位；高度受限时，仅在选中卡片实际超出视口后滚动。
- 2/4/6/8 个有窗口工作区分别显示为 1×2、2×2、2×3、2×4；奇数工作区保留末行空位。
- 卡片显示真实窗口内容与布局，右上角显示小号、半透明背景的编号/名称，选中时出现主题色细边框，背景颜色保持一致；多屏可附显示器名称，不显示底部“工作区”、窗口数量或当前/上一个文字。
- 保持面板打开，让后台终端输出或视频内容变化，确认预览随之更新；窗口移动/缩放后预览几何更新，不重排候选。
- 捕获不可用或源窗口关闭时显示图标/名称或移除对应窗口；滚出视口及关闭面板后停止捕获。
- 连续窗口/工作区快速回切，以及目标关闭后的有效历史回退。
- 左右 Alt/Super、快速点按、按住长时间、只松开 Shift/Tab、同类双修饰键和重复 Tab。
- 全屏、最大化、XWayland、模态与分组窗口的焦点核对及层叠顺序。
- 来源显示器断开、热重载、停用及锁屏中断后的输入恢复。
- 主题、字体、语言、圆角与动画开关；1.0/1.6/2.0 缩放、旋转、负坐标和混合 DPI。
- 安装、重复更新、`--no-bindings`、卸载与重复卸载；用户后来新增绑定/其他插件仍保留。

当前窗口预览为图标/标题，工作区使用实时窗口捕获合成预览。单屏普通窗口的首帧和后台
内容刷新已实测；缓存、GPU/内存预算与上述完整兼容矩阵尚未验收。
本机测试记录见 [开发版验证记录](../../docs/development-validation.md)。
