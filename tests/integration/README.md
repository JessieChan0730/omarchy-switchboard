# 桌面集成验收

## 官方安装命令与快捷键生命周期

```bash
python3 tests/integration/plugin-lifecycle.py --deploy --restart-shell
```

测试开始前原实例须已就绪且面板关闭。`--deploy` 通过本地安装器检查并部署，保留已有
快捷键模式；省略该参数可测试已安装构建。`--restart-shell` 同时验收 shell 重启。
测试会短暂停用并重新启用 Switchboard、重载 Hyprland，并注册一次无心跳的临时 Lua
所有者验证真实租约过期后的恢复。它不切换 `--bindings` / `--no-bindings`。

Git 安装、更新、禁用、启用和移除使用官方命令、真实 shell 和真实 Git 仓库。
临时插件采用独立 ID，运行代码复制自根目录 `runtime/`；验证首次 Git 安装默认开启快捷键，
期间停用原实例避免竞争，更新夹具使用新的运行路径。该部分验证 Git 分发和加载，原实例部分验证快捷键生命周期，
报告中分别注明。临时仓库和完整桌面快照位于 `.cache/plugin-lifecycle/<时间戳>/`，
断言与恢复说明位于 `test-results/plugin-lifecycle-<时间戳>/`，均不默认加入 Git。

正常结束、失败或收到中断信号后均执行清理：移除测试插件与其配置条目，恢复原实例启用
状态，核对快捷键模式、配置错误、显示器布局、原工作区 ID、窗口归属和焦点。结果资料
保留给用户查看，可在用户确认后删除。本测试不代替物理键盘按住/释放时序和下方多屏验收。

## 窗口与工作区界面

`npm run test:qt` 另含真实 `WorkspaceSwitcher`/`WindowSwitcher` 组件的离屏布局回归，覆盖
1600×900（2560×1440、1.6 缩放）下的 9/10 项、含来访工作区的 12 项、较小屏幕、纵向/超宽预览、最小卡片滚动，
超过 12 项后固定四列、卡片尺寸保持和逐项滚动（13/16/17/40 项）、恢复 12 项后停止滚动，
以及应用图标和窗口气泡的单行横向滚动；第 10 个工作区槽位显示为 `0`；工作区来访角标使用 `↳ 全局 ID`，
并覆盖非首屏编号段、显示器名称开关及悬停说明的纯文本渲染。它不切换或创建真实工作区，不代替下方桌面验收。

先运行 `./scripts/install.sh`，通过 `omarchy-shell shell summon jessie.switchboard
'{"mode":"workspace"}'` 或窗口模式测试面板。`status` 应报告 ready 和候选数量。
已有安装使用 `./scripts/install.sh` 保留当前绑定模式，不为测试切换 `--bindings` / `--no-bindings`。
本清单覆盖 `Win+Tab`、`Win+Shift+Tab`、`Alt+Tab`、`Alt+Shift+Tab`、
`Alt+反引号`、`Alt+Shift+反引号` 六个全局快捷键。Win 对应 Hyprland 的 Super。
反引号是键盘上的 ` / ~ 键；Win+反引号及 Win+Shift+反引号继续用于 Quake console。

按计划书记录以下实机结果，不能用 offscreen 或假适配器替代：

- 当前 Omarchy、Hyprland、Quickshell、Qt 版本。
- 六个组合各只有一个插件绑定；Quake console 和其他系统快捷键保持原行为。
- 应用图标和窗口气泡均限定打开时的当前工作区；多屏时也不包含同屏其他工作区。
- 当前工作区没有可切换应用时，Alt+Tab / Alt+反引号及其 Shift 反向入口均不显示面板、不接管键盘焦点；只有一个应用时仍可打开，最后一个候选应用消失后自动收起。
- Alt+Tab / Alt+Shift+Tab 的图标面板延迟约 100ms 显示；快速点按在显示前松开 Alt 能确认且不显示面板，持续按住才显示。延迟期间连续 Tab 不丢步、Esc 可取消，取消或确认后不会迟到显示；命令打开、Alt+反引号及 Win+Tab 立即显示。
- 同工作区三个终端、两个浏览器只出现两个应用图标，数量为 3 / 2，确认应用进入其最近窗口。
- 应用名下方显示较淡的目标窗口标题：主层与该应用最近使用的窗口一致，切应用、标题变化及默认目标关闭时同步；展开气泡后与所选窗口一致。长标题保持一行省略，空标题隐藏，包含标记的标题按纯文本显示。
- Alt+反引号从聚焦应用进入，或在应用列表中操作高亮应用；保留当前工作区的所有应用图标，仅高亮选中应用，气泡指向该图标且只列出它的窗口；Shift 反向、Esc 取消，松 Alt 确认。
- 窗口气泡每项显示实时内容，Tab 收起气泡继续切应用，两行均能横向滚动。
- 窗口关闭或移出时同步，选中窗口消失自动取消；确认不会跟随窗口切到其他工作区。
- 分别聚焦两台显示器后打开 Win+Tab，正反向循环不出现其他屏幕的工作区，确认不改变其他屏幕焦点。
- 选择后把目标工作区移到另一块屏幕，确认时拒绝跨屏激活；来源显示器断开时关闭面板。
- 选择期间真实窗口/工作区保持原状，Esc 取消后仍保持；确认后真实目标获得焦点。
- 候选数量跟随来源屏幕的顶部栏：该屏幕前 5 个槽位，加实际位于该屏幕的额外编号/来访工作区；空工作区也参与正反向循环，按当前/上一个/MRU 排序。
- 来源屏幕十槽全满后，另一台屏幕的工作区移入或拔屏合并，概览仍列出所有额外数字工作区，数量可超过 10；本屏段显示 `1–9、0`，段外显示 `↳ 全局 ID`，保留各自的预览和确认目标。仅剩一屏或关闭显示器名称后，来访标记仍显示。
- 保持面板打开时，来访工作区加入后追加到末尾，离开后移除，已有项相对顺序和选中身份保持；选中项被移走或重新编号时关闭面板，重新打开使用最新编号，不跨屏激活或重建消失的来访 ID。
- 顶部显示 1–6、工作区 4 为空时，概览仍有 6 项并显示工作区 4 的桌面壁纸；仅打开、步进或取消不创建该工作区，确认后可切到 4，再通过工作区面板选回原工作区。
- 第 7 个工作区存在而 6 不存在时，顶部栏与概览均显示 1–5 和 7，不额外补齐 6 或 8–10。
- 从空工作区打开时，以当前项为锚点按方向选择；仅一个有窗口工作区或所有工作区为空时仍可切到其他空槽位。
- 顶部工作区标题、底部新建入口和按键提示均不显示。
- 面板按卡片行数调整高度；卡片过多时滚动仍可显示选中项，方向键到末行后不会选中隐藏操作。
- 面板打开时，普通方向键、按住 Win/Alt 及同时按住 Shift 都能移动选择；左右不跨行，
  上下保持同列，边缘和末行空位保持原选择。每次 Tab / Shift+Tab 只步进一次；Esc/Enter
  关闭面板后释放快捷键抑制，Win+方向键恢复系统或用户用途。
- 卡片全部可见时，从首行切到末行再返回，网格保持原位；高度受限时，仅在选中卡片实际超出视口后滚动。
- 2560×1440、1.6 缩放下的 9 项按可用高度缩小，三行完整显示；逐项选到第三排再返回不滚动。
- 编号与左上角顶部栏一致，第 10 个槽位显示 `0`，确认后切到内部 ID 10；第二台显示器的内部 ID 20 也显示 `0`。
- 网格按全部候选数量排列，6/8 项分别显示为 2×3、2×4；奇数工作区保留末行空位。
- 超过 12 项时固定四列，卡片和面板沿用 12 项时的尺寸；鼠标可滚动，键盘选择第四行及之后的项时自动显示，返回首行恢复滚动位置。
- 可滚动的工作区及窗口网格右侧显示细位置提示，滑块比例对应可见范围，鼠标和键盘滚动
  同步更新位置；到达顶部/底部时到达轨道两端，内容全部可见后隐藏，不占用卡片宽度。
- 卡片显示真实窗口内容与布局，右上角显示小号、半透明背景的编号/名称，选中时出现主题色细边框，背景颜色保持一致；多屏可附显示器名称，不显示底部“工作区”、窗口数量或当前/上一个文字。
- 保持面板打开，让后台终端输出或视频内容变化，确认预览随之更新；窗口移动/缩放后预览几何更新，不重排候选。
- 捕获不可用或源窗口关闭时显示图标/名称或移除对应窗口；滚出视口及关闭面板后停止捕获。
- 捕获临时停止且来源未变时，按 250/500/1000ms 最多重试三次，恢复内容持续两秒后重置次数；
  持续失败保持图标/名称，滚出视口、关闭面板或来源消失后不再重试，重新可见或更换来源可重新尝试。
- 空卡片只有桌面壁纸且不加载窗口捕获；切换壁纸后打开面板使用新壁纸，保持面板打开时也跟随壁纸变化。
- 大尺寸 WebP 壁纸提前生成小图并预加载；连续打开和取消后，小图引用仍保留，卡片首帧使用共享缓存，
  不重新解码原壁纸。卡片尺寸变化也不触发原图解码；同路径文件替换刷新缓存，生成期间换壁纸不发布过期结果。
- 连续正反向打开窗口/工作区面板，MRU 排序正确；关闭的窗口不进入候选队列。
- 左右 Alt/Super、快速点按、按住长时间、只松开 Shift/Tab、同类双修饰键和重复 Tab。
- 全屏、最大化、XWayland、模态与分组窗口的焦点核对及层叠顺序。
- 来源显示器断开、热重载、停用及锁屏中断后的输入恢复。
- 主题、字体、语言、圆角与动画开关；1.0/1.6/2.0 缩放、旋转、负坐标和混合 DPI。
- 安装、重复更新、`--no-bindings`、卸载与重复卸载；用户后来新增绑定/其他插件仍保留。

当前同应用窗口气泡及工作区均使用实时窗口捕获；应用主层仅显示图标及多窗口数量。单屏普通窗口的首帧和后台
内容刷新已实测；缓存、GPU/内存预算与上述完整兼容矩阵尚未验收。
本机测试的截图、断言和恢复记录保存在 `test-results/`，不默认加入 Git。
