# 开发版验证记录

2026-11-12 支持范围更新：插件以轻量为目标，仅规划 `Win+Tab`、`Win+Shift+Tab`、
`Alt+Tab` 和 `Alt+Shift+Tab` 四个全局快捷键；Win 对应 Hyprland 的 Super。

不作为当前规划的交付或验收要求。本次文档调整没有新增运行验证。

日期：2026-11-08。运行环境：Omarchy 4.5.0-3、Hyprland 0.56.2、Quickshell
0.3.2.r7.g2b4501a-1、Qt 6.12.0。单显示器 eDP-2，2560×1440，缩放 1.6。

安装器 7 项通过，覆盖更新、构建 ID 检查、回滚、原插件恢复、保留后续用户修改和 shell 不可用时卸载。

实际 Wayland 会话已验证：

- 插件报告就绪，命令打开窗口面板和十槽位工作区网格。
- 当前工作区两窗口：打开时焦点保持，确认切到另一窗口，连续快速回切可在二者之间往返。
- 工作区选择期间真实工作区保持；确认后切换，连续工作区快速回切正确。
- 反向初始选择合法空槽位 10；仅打开不实例化，确认后创建，回切可重新创建该合法空槽位。
- 步进后取消保持原工作区，不留下覆盖层。
- 全局快捷键触发时修饰键已经松开，实际状态查询会完成确认并激活目标。
- `--bindings` 后四个 Tab 组合各只有一个插件绑定，两个 grave 入口正确接管。
- 停用后运行状态租约清除；卸载与重复卸载通过，原绑定文本及 shell.json 语义与安装前相同。
- 面板目视检查：主题、中文、选中边框、应用图标/名称及几何占位显示正常；修复首次滚动裁切。

核对新实例 buildId 后才报告成功；旧的 ready 响应不能通过更新检查。

尚未验收：真实窗口截图、缓存/GPU 预算、冷/热启动延迟目标；真实左右修饰键双持、

当前图标与几何布局占位不构成截图能力验证。全局快捷键的程序触发不构成物理按键时序验收。
