`Alt+Tab` 和 `Alt+Shift+Tab` 四个全局快捷键；Win 对应 Hyprland 的 Super。

2026-11-14 九宫格高度与顶部栏编号修正。

- 此前末行间距修正只覆盖卡片已经全部放下的情况。本机 2560×1440、1.6 缩放后为
  1600×900；固定 480 像素卡片宽度使九宫格需要 842 像素，而面板内容最多只有 796
  像素，因此第三排仍会滚动。改为先按可用高度等比例缩小卡片，再确定面板宽高；
  卡片最小高度为 100 像素，达到最小值仍放不下时继续支持滚动。
- 工作区卡片和窗口卡片的工作区副标题均把第 10 个槽位显示为 `0`，内部 ID 与
  `localSlot` 不变，第二个编号段的 ID 20 也显示 `0`。
- `npm run check` 通过 43 项 Qt 测试、7 项安装器测试、TypeScript、零警告 QML lint、
  manifest 和 Lua/Bash 检查。新增真实 Quickshell 组件的 8 组布局回归和编号验证，
  覆盖 6/8/9/10 项、1600×900/1280×720、纵向/超宽预览、最小卡片滚动和返回首行。
  对隔离的测试副本恢复固定 480 像素卡片宽度后，九宫格用例失败，确认能捕获原问题。
- 独立 Wayland 探针使用真实 `Overlay.qml`，仅注入 9/10 项候选。9 项内容区域为
  1390.22×796，10 项为 1512×649.625，逐项选择时 `contentY` 始终为 0，滚动交互关闭，
  ID 10 的角标为 `0`。探针结束关闭面板，没有创建或切换真实工作区。
- 核对本机 Omarchy 4.5.0-3 的 `default/hypr/monitor-workspaces.lua` 和顶部栏
  `Workspaces.qml`：默认每台显示器分配 10 个槽位，顶部栏把第 10 个显示为 `0`；
  插拔合并时，超出本地槽位的工作区仍可作为来访工作区保留。10 个槽位不是系统总量
  上限，Hyprland 支持更多编号工作区和命名工作区。数量核实仅阅读源码。
