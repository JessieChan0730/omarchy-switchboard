# 已知问题与后续适配

## 普通命名工作区

记录日期：2026-11-14。状态：暂缓，实际遇到后再适配。

Omarchy 默认使用每台显示器的数字槽位，顶部栏不列出普通命名工作区。用户自行配置
Hyprland 时仍可能创建名为 `a`、`coding` 的普通工作区。

当前 Switchboard 的 Win+Tab 只列出数字工作区，因此普通命名工作区不会进入概览。
将数字工作区改为自定义名称时，角标仍优先显示本地编号，不显示该自定义名称。

后续遇到此类使用需求时，再处理以下内容：

- 在来源显示器范围内纳入普通命名工作区，继续排除 scratchpad、Quake console 等特殊工作区。
- 右上角直接显示自定义名称，例如 `a`；兼顾数字槽位的 `1–9、0` 显示规则。
- 覆盖重命名后的身份、选择保持和确认激活；显示动态名称时保持纯文本渲染。

本次多显示器与来访数字工作区修复不改变以上行为。
